To find the total number of chairs in the bakery, we need to calculate the number of chairs for both indoor and outdoor tables separately and then add them together.

   - There are 8 indoor tables.
   - Each indoor table has 3 chairs.
   - To find the total number of chairs for the indoor tables, we multiply the number of tables by the number of chairs per table:
     \[
     \text{Chairs for indoor tables} = 8 \text{ tables} \times 3 \text{ chairs/table} = 24 \text{ chairs}
     \]

2. **Calculate the number of chairs for outdoor tables:**
   - There are 12 outdoor tables.
   - Each outdoor table also has 3 chairs.
   - To find the total number of chairs for the outdoor tables, we perform a similar multiplication:
     \[
     \text{Chairs for outdoor tables} = 12 \text{ tables} \times 3 \text{ chairs/table} = 36 \text{ chairs}
     \]

3. **Calculate the total number of chairs in the bakery:**
   - Now that we have the number of chairs for both indoor and outdoor tables, we can add them together to find the total number of chairs:
     \[
     \text{Total chairs} = \text{Chairs for indoor tables} + \text{Chairs for outdoor tables} = 24 \text{ chairs} + 36 \text{ chairs} = 60 \text{ chairs}
     \]

Therefore, the total number of chairs in the bakery is 60.
