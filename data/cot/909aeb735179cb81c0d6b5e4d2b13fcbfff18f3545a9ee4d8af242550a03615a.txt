<reasoning>
To determine the number of ants in the third anthill, we will start with the number of ants in the first anthill and calculate the number of ants in the subsequent anthills using the given percentage decrease.

1. **Identify the number of ants in the first anthill.**  
   We know that there are 100 ants in the first anthill.
   \[
   \text{Ants in the first anthill} = 100
   \]

2. **Calculate the number of ants in the second anthill.**  
   The second anthill has 20% fewer ants than the first. To find 20% of 100, we calculate:
   \[
   20\% \text{ of } 100 = \frac{20}{100} \times 100 = 20
   \]
   Therefore, the number of ants in the second anthill is:
   \[
   \text{Ants in the second anthill} = 100 - 20 = 80
   \]

3. **Calculate the number of ants in the third anthill.**  
   The third anthill also has 20% fewer ants than the second. We first find 20% of 80:
   \[
   20\% \text{ of } 80 = \frac{20}{100} \times 80 = 16
   \]
   Thus, the number of ants in the third anthill is:
   \[
   \text{Ants in the third anthill} = 80 - 16 = 64
   \]

In conclusion, after calculating the number of ants in each anthill, we find that the third anthill contains 64 ants.
</reasoning>
<answer>64</answer>
